PART 1: LONGITUDINAL AUTO-INSERTION FOR SEMESTER 8 EVALUATION STATEMENT
================================================================================
1. Database Schema Extension (`cumulative_academic_summary`):
   Ensure `cumulative_academic_summary` stores granular history for every student:
   - `sem1_credits` (12), `sem1_sgpa`, `sem1_pct`
   - `sem2_credits` (31), `sem2_sgpa`, `sem2_pct`
   - `sem3_credits` (17), `sem3_sgpa`, `sem3_pct`
   - `sem4_credits` (21), `sem4_sgpa`, `sem4_pct`
   - `sem5_credits` (11), `sem5_sgpa`, `sem5_pct`
   - `sem6_credits` (21), `sem6_sgpa`, `sem6_pct`
   - `sem7_credits` (26), `sem7_sgpa`, `sem7_pct`
   - `sem8_credits` (12), `sem8_sgpa`, `sem8_pct`
   - `total_credits` (151.0), `cgpa`, `overall_percentage`, `overall_grade`, `grading_performance`, `final_result`

2. Automatic Data Pipeline:
   - When any semester examination (Sem 1 to 7) is approved, automatically upsert that semester's credits, SGPA, and Percentage into `cumulative_academic_summary`.
   - When the 8th Semester marksheet is generated:
     * Automatically fetch the historical records (Sem 1 through 7) for that student's `enrollment_no` / `roll_no`.
     * Merge with the newly calculated 8th Semester scores.
     * Compute CGPA: Sum(Credits_i * SGPA_i) / 151.0 (rounded to 2 decimal places).
     * Compute Overall Percentage: Sum(Semester_Percentages) / 8.0 (rounded to 2 decimal places).
     * Determine Overall Letter Grade and Grading Performance from INC 10-Point Scale:
       - >= 85%: O (Outstanding)
       - 80.00% - 84.99%: A+ (Excellent)
       - 75.00% - 79.99%: A (Very Good)
       - 65.00% - 74.99%: B+ (Good)
       - 60.00% - 64.99%: B (Above Average)
       - 50.00% - 59.99%: C (Average)
       - < 50.00%: F (Fail)
     * If all 8 semesters are passed, set `final_result = 'PASS'`. If any semester has pending backlogs, set `final_result = 'FAIL'`.
